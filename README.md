# 📘 English Janala Web App

An interactive **English vocabulary learning web application** designed to help users improve their English skills through structured lessons, dynamic word data, and an engaging UI.

🔗 **Live Demo:**
https://abdhullah-al-maruf.github.io/English-janala-web-app/

---

## ✨ Features

* 📚 Learn English vocabulary by levels
* 🔄 Dynamic lesson loading using API
* 🔍 View word meaning, pronunciation & examples
* 📦 Modal-based detailed word view
* 🎯 Interactive lesson selection
* 🔐 Simple login & logout system
* ❓ FAQ section for JavaScript concepts
* ⚡ Loading spinner for better UX
* 🚫 Handles empty/no data cases
* 🎨 Clean and responsive UI design

---

## 🛠️ Tech Stack

### Frontend

* 🌐 HTML5
* 🎨 CSS3 / Tailwind CSS
* ⚡ JavaScript (ES6+)

### API

* 📡 Programming Hero Open API

---

## 🔌 API Endpoints Used

```bash
# Get all levels
https://openapi.programming-hero.com/api/levels/all

# Get words by level
https://openapi.programming-hero.com/api/level/{id}

# Get word details
https://openapi.programming-hero.com/api/word/{id}

# Get all words
https://openapi.programming-hero.com/api/words/all
```

## 🚀 How It Works

1. User logs in using a simple validation system
2. Lessons are fetched dynamically from API
3. Clicking a lesson loads related vocabulary
4. Users can:

   * View word meaning
   * See pronunciation
   * Open modal for detailed info
5. UI updates dynamically with loading states
